## The line

> I asked my AI assistant to write my resignation letter. It quit first.

## How it works

`main.py` writes that single line — 70 characters, well under the
200-character cap — to `/output/entry.txt`. The house gate checks the file
is UTF-8 text of 1 to 200 characters, and the judge then compares it two
at a time against the other entries.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
